# 🌊 AI-Assisted Marine Risk Intelligence & Community Reporting Platform

An AI-assisted geospatial marine intelligence platform developed during my internship at **MARS Group** to identify marine risk zones and support faster environmental response.

The project combines **satellite Sea Surface Temperature (SST) data, ocean chemistry parameters, GIS analysis, and community-reported coastal incidents** into an interactive intelligence platform.

## 🚀 Key Contributions

* Collected and processed marine datasets from **NOAA, OISST, NCEI, and OceanSODA**
* Cleaned and validated large-scale environmental datasets using **Python**
* Calculated **SST anomalies** using the 1991–2020 climatology baseline
* Integrated **pH, salinity, and CO₂** parameters into a marine risk framework
* Resolved satellite longitude conversion issues (0–360° → −180° to +180°)
* Optimised geospatial datasets for improved computational performance
* Prepared GIS-ready datasets and supported downstream database, backend, and dashboard development
* Maintained technical documentation and collaborated within an **8-member cross-functional team**

## 🛠️ Technologies

**Python · Pandas · NumPy · Xarray · QGIS · PostgreSQL · PostGIS · Node.js · REST API · Prisma · Streamlit · Plotly · Git**

## 🎯 Project Impact

The platform aims to transform complex marine and satellite data into **actionable environmental intelligence**, helping NGOs, coastal authorities, and research organisations identify at-risk marine zones and respond more effectively to ecological threats.
